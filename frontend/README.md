# Frontend

Next.js (App Router) + TypeScript frontend for the expense tracker. See the [repo root README](../README.md) for full setup instructions (backend + frontend together), and [`../context.md`](../context.md) for architecture/repo layout.

Quick start (assumes the backend is already running — see the root README):

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

Then visit `http://localhost:3000`.
